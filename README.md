# ShopDesk — Offline Shop Management System

A responsive inventory and sales dashboard built with vanilla HTML, CSS and JavaScript. No backend or API key required.

## Features
- Add products with cost, sale price and stock
- Search and delete inventory entries
- Record sales with stock validation and automatic deduction
- Track stock value, revenue and gross profit
- View recent sales
- Export JSON backups
- Responsive interface with localStorage persistence

## Run
Open `index.html` in a modern browser.

## Deploy
GitHub Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Limitations
Data is stored only in the current browser. Clearing browser data removes it unless exported. JSON backup import is not supported. Gross profit excludes operating expenses.

## Tech
HTML, CSS, JavaScript, localStorage.
